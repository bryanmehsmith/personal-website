  \item Designed and maintained dimensional models, data contracts, database schemas, access controls, and

    Microsoft Graph, Adaptive Cards, Entra identities, SAML, and Key Vault.
  \item Embedded OCR, transcription, LLM extraction, classification, unsupervised modelling, and agent
    routing into operational workflows, with human review and engineering safeguards. Built a spam detection
    agent powered by an LLM for inbound messages and a query router agent for tools, workflows, or specialists.
  \item Diagnosed reporting and data issues end to end by tracing symptoms through reports, semantic models,
    pipelines, historical records, and source rows.
  \item Applied automated testing, CI/CD, infrastructure as code, least privilege, observability, deployment
    gates, and rollback safeguards across platform changes.
  \item Partner with stakeholders and vendors on requirements, architecture, rollout, production support,
    platform tradeoffs, and build versus buy decisions. Mentor engineers and review code.
